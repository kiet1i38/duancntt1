1. Phép chạy đang thực hiện

Câu hỏi nghiên cứu

“Có thể giảm reasoning tokens mà không làm giảm accuracy, và mức compression có thể thay đổi theo độ khó bài toán không?”

Difficulty là biến trung tâm; uncertainty/entropy/confidence chỉ là tín hiệu phụ.

Policy SD-TokenSkip đã khóa

Nhóm bàiRatioChế độ
Easy0.5TokenSkip compression
Medium1.0Full-CoT
Hard1.0Full-CoT

Mỗi bài chạy Full-CoT, fixed 0.5, fixed 0.7 và fixed 0.9. SD lấy fixed 0.5 cho easy và Full-CoT cho medium/hard.

4. Cài đặt trên Windows mới

Bước 1 — Clone và tạo môi trường

git clone https://github.com/kiet1i38/duancntt1.git
cd duancntt1
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip

Nếu PowerShell chặn activate, chạy trực tiếp bằng .\.venv\Scripts\python.exe.

Bước 2 — Cài PyTorch có CUDA

Máy cũ dùng torch 2.5.1+cu121. Cài bản CUDA phù hợp driver/GPU theo hướng dẫn PyTorch, rồi kiểm tra:

python -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'NO GPU')"

Nếu CUDA: False, chưa chạy full.

Bước 3 — Cài thư viện runner

pip install -r test\requirements-sd-run.txt
python -c "import transformers, peft, accelerate, bitsandbytes; print('dependencies: OK')"

Bước 4 — Kiểm tra dataset và syntax

(Get-Content test\TokenSkip-official\datasets\gsm8k\train.jsonl).Count
(Get-Content test\TokenSkip-official\datasets\gsm8k\test.jsonl).Count
python -m py_compile test\run_full_sd_tokenskip.py test\tokenskip_pilot_core.py

Hai số dòng cần là 7473 và 1319. Compile không chạy model.

5. Lệnh chạy tiếp full evaluation

Chạy từ thư mục gốc repository. Hugging Face sẽ tải model và adapter ở lần đầu.

python test\run_full_sd_tokenskip.py --base-model Qwen/Qwen2.5-3B-Instruct --adapter-path hemingkx/TokenSkip-Qwen2.5-3B-Instruct-GSM8K --cal-data test\TokenSkip-official\datasets\gsm8k\train.jsonl --eval-data test\TokenSkip-official\datasets\gsm8k\test.jsonl --output-dir test\full-sd-tokenskip-gsm8k-512 --cal-pool 0 --n-cal 9 --n-eval 1319 --max-new-tokens 512
Giữ nguyên: --n-eval 1319, --max-new-tokens 512, model, adapter và dataset.
Không: xóa output, đổi model/dataset hoặc dùng run nhỏ làm full result.

6. Resume và theo dõi

Runner ghi từng bài thành một dòng JSONL với flush/fsync. Khi chạy lại, các ID đã có sẽ được bỏ qua.

FileÝ nghĩa
calibration_rows.jsonl9 bài calibration; snapshot có 8 bài.
evaluation_rows.jsonl1.319 bài test; tạo khi evaluation bắt đầu.
run_meta.jsonModel, seed, thresholds, policy và caveat.
full_results.jsonChỉ có sau khi đủ evaluation.

Theo dõi

Get-Content test\full-sd-tokenskip-gsm8k-512\run.stdout.log -Wait

# Cửa sổ khác:
Get-Process python -ErrorAction SilentlyContinue
(Get-Content test\full-sd-tokenskip-gsm8k-512\calibration_rows.jsonl).Count
(Get-Content test\full-sd-tokenskip-gsm8k-512\evaluation_rows.jsonl -ErrorAction SilentlyContinue).Count

Dừng an toàn: nhấn Ctrl+C. Nếu dừng giữa generation, dòng đó chưa được ghi; chạy lại sẽ tiếp tục. Không chạy hai runner cùng output.

7. Kiểm tra kết quả cuối

Chỉ khi có full_results.json mới tổng hợp full split.

$result = Get-Content test\full-sd-tokenskip-gsm8k-512\full_results.json | ConvertFrom-Json
$result.result_classification
$result.summaries | ConvertTo-Json -Depth 5
$result.per_bin.sd_tokenskip | ConvertTo-Json -Depth 5

Phải báo cáo

  • Accuracy/Exact Match của Full, fixed 0.5/0.7/0.9 và SD.
  • Average/tổng reasoning tokens, latency tổng và tokens-per-correct.
  • Accuracy, tokens, latency riêng cho easy/medium/hard.
  • Token reduction và accuracy delta của SD so với Full.
Reported result: bài báo công bố.
Official repository result: code/checkpoint chính thức.
Reproduced result: chạy lại đúng protocol tương thích.
Extension result: model/dataset mới, tách riêng.

8. Lỗi thường gặp

CUDA: False

Kiểm tra driver NVIDIA, cài PyTorch CUDA đúng bản và mở lại venv. Không chạy 3B trên CPU để lấy kết quả.

CUDA out of memory

Kiểm tra không có runner khác. Runner hiện dùng 4-bit. Không tự giảm max tokens trong run chính; nếu phải đổi, tạo extension và ghi rõ.

Hugging Face download lỗi

Kiểm tra Internet, model ID, dung lượng ổ đĩa và quyền ghi cache. Không commit cache model vào Git.

ModuleNotFoundError

Activate đúng .venv, cài requirements và chạy từ thư mục gốc repository.

Chạy trùng hoặc lỗi JSONL

Dừng runner khác, chỉ dùng một output directory và không sửa tay dòng đã ghi. Sao lưu trước nếu cần kiểm tra file hỏng.

9. Checklist trước khi đưa vào báo cáo

  • Model reproduction là Qwen/Qwen2.5-3B-Instruct.
  • Adapter là checkpoint TokenSkip GSM8K chính thức.
  • Dataset đúng train/test JSONL, đủ 1.319 test rows.
  • Prompt, evaluator, seed 42 và max tokens 512 không đổi.
  • Policy easy/medium/hard khóa trước khi xem nhãn test.
  • Fixed và adaptive chạy trên cùng test rows.
  • Pilot 27 bài và 4-bit local không được gọi là reproduced result.
  • Extension được tách khỏi reproduction.
  • Nếu kết quả xấu, giữ nguyên và báo cáo negative result; không sửa số liệu.
